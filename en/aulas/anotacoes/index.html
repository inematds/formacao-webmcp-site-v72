Lesson 5 · 16 min

Annotations and confirmation: readOnly, consequential and untrustedContent

An annotation is a hint the page gives to the agent and the browser: this tool only reads, this one has consequences, this one returns third-party text. A hint is not a lock. That is why the kit's action with side effects also waits for the person to click Confirmar. In this lesson you set the annotations and see the confirmation work.

Start the lesson

In this lesson you will

  1. 1readOnlyHint: only reads, changes nothing
  2. 2consequentialHint and the on-screen confirmation
  3. 3untrustedContentHint: the output carries third-party text
  4. 4Responding to the request to remove the confirmation

Goal: mark each tool with the right annotation and make the action with consequences wait for the person to click Confirmar on the screen.

01 · Three annotations, one gate

Click each one. All are booleans and start as false.

An annotation is not authorization. Validate the input in execute and on the server as if the call came from anywhere.

Annotations checked against the 10/16/2026 spec (there is also debugging, for debugging tools). They may change.

03 · Confirmation on screen

reservar_vaga prepares, shows the panel, and waits. Recusar returns reservado:false; Confirmar saves it and shows it in the list.

Excerpt · kit/pagina/ferramentas.mjs
annotations: { consequentialHint: true },
execute: comErroUtil(async ({ id, nome }, { signal }) => {
  const oficina = agenda.oficina(id);
  if (!oficina) throw new Error(`oficina não encontrada: ${id}`);
  const ok = await ui.pedirConfirmacao({ oficina, nome }, signal);   // humano decide
  if (!ok) return { reservado: false, motivo: 'a pessoa recusou na tela' };
  const reserva = agenda.reservar({ id, nome });
  ui.mostrarReservas();
  return { reservado: true, reserva };
})
Terminal · decline and confirm
cd ~/projetos/formacao-webmcp-site-v72/kit
node scripts/executar.mjs nativo reservar_vaga '{"id":"of-301","nome":"Rita"}' --recusar; echo "saída: $?"
node scripts/executar.mjs nativo reservar_vaga '{"id":"of-301","nome":"Rita"}' --confirmar; echo "saída: $?"

executar.mjs plays the part of the person: it waits for the panel to appear and clicks the requested button.

Marking consequentialHint: true and saving straight in execute leaves the decision to the agent. Lesson 8 shows the test battery catching exactly this: with the confirmation swapped for const ok = true, the check "reserva recusada na tela não reserva" fails.

    07 · In three sentences

    HintreadOnlyHint, consequentialHint and untrustedContentHint inform the agent; they don't authorize anything.
    GateAn action with an effect only writes after the person confirms on the screen.
    Outside textOutput with third-party content is data, never instruction: mark it and don't act on it.
