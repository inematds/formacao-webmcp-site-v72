Lesson 8 · 18 min

Test it yourself: run the suite in all three modes, checklist and plan

A tool is only ready when a test proves it works and that the page stays the same without it. The kit's test suite runs with no model in all three modes, compares tool with form, and tests the confirmation and the cleanup. In this lesson you run it, watch a break get caught and leave with a dated plan for your site.

Start the lesson

  3. 3The checklist before you publish

Goal: run the automatic test suite in all three modes, watch a break get caught and leave with the checklist and the dated plan for your page.

In the polyfill, getTools after pagehide gives NotAllowedError: it shuts the whole API off. The test accepts both ways of "leaving": zero tools and toolchange fired.

FALHA [nativo] reserva recusada na tela não reserva
BATERIA: 12/13 ok
saída: 1

Someone replaces the wait for the click with const ok = true to "speed things up". The test suite fails on "reserva recusada na tela não reserva" and exits with 1. That is what it is for.

03 · Cause the break

The rehearsal copies the page, makes the dangerous swap in the copy and runs the test suite in native mode only.

Terminal · provoked break
cd ~/projetos/formacao-webmcp-site-v72/kit
E=${TMPDIR:-/tmp}/ensaio-webmcp-site/a8; rm -rf $E; mkdir -p $E; cp -r pagina/. $E/
# the dangerous "optimization": booking without waiting for the person
sed -i 's/const ok = await ui.pedirConfirmacao({ oficina, nome }, signal);/const ok = true;/' $E/ferramentas.mjs
PAGINA=$E node scripts/testar.mjs nativo | grep -E "FALHA|BATERIA"; echo "saída: ${PIPESTATUS[0]}"

04 · Checklist before you publish

Dated: 10/19/2026, spec from 10/16/2026.

1. Fallback

The site works the same without document.modelContext.

No polyfill in production: it is only for the rehearsal.

2. Catalog

validar-catalogo.mjs with 0 errors.

Each tool has one intent and the right annotation.

3. Effect

Every tool with consequentialHint waits for the person.

Battery with the "decline" case passing.

4. Date

A comment with the spec date in the tools file.

Origin trial token with the end date (Chrome 156) in your calendar.

ReminderWhen the spec changes date, run the battery and reread what changed.
