Lesson 2 · 15 min

Setup: flag, origin trial, polyfill, and three test modes

You don't need an experimental Chrome installed to work. The kit serves the page on a local server and opens the same Playwright Chromium in three modes: without the API, with the polyfill, and with native WebMCP behind the test flag. No cost and no API key.

Start the lesson

In this lesson you will

  1. 1Clone the kit and install it with pinned versions
  2. 2Secure context: https in production, 127.0.0.1 for rehearsal
  3. 3The three modes: sem, polyfill, and nativo
  4. 4Origin trial and flag in your Chrome, when you want to see it live

Goal: set up the kit and see the same page in three modes (no API, polyfill, native) without spending quota or installing an experimental Chrome.

01 · The same page, three browsers

Click each mode.

The API only exists in a secure context: https or localhost/127.0.0.1. That is why the kit serves the page at 127.0.0.1.

Always test the No API mode: it is what most visitors see.

02 · Clone and install the kit

Versions pinned on 10/19/2026: @mcp-b/webmcp-polyfill 6.0.3 and playwright 1.64.0. The postinstall copies the polyfill to pagina/vendor/ (for rehearsal only).

In the No API mode, the page shows a notice and carries on through the form. In the other two, it registers 4 tools. In none of them does navigator.modelContext exist.

04 · See it in your Chrome (optional)

Experimental as of 10/19/2026. Nothing here is a done-when criterion.

1. Flag

Open chrome://flags/#enable-webmcp-testing, turn it on, and restart Chrome.

Run the kit's server and open the URL it prints.

Servercd kit && node scripts/servir.mjs

2. Polyfill

Without the flag, add ?ensaio=polyfill to the URL.

The page loads the polyfill from pagina/vendor/ and registers the same tools.

URLhttp://127.0.0.1:[porta]/?ensaio=polyfill

3. Inspector

Google publishes the Model Context Tool Inspector extension, which lists the tools and calls them in natural language.

It asks for an API key for a model (Gemini). It is not needed in this course.

4. Production

Register your domain in the WebMCP origin trial and paste the token into the meta tag at the top of kit/pagina/index.html.

The token is registered for the site's domain; on localhost, use the flag.
