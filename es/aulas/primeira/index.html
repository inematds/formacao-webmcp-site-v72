Clase 3 · 18 min

Primera tool: registerTool con inputSchema y execute

Una tool de WebMCP es un objeto con nombre, descripción, esquema de entrada y una función execute. La página la registra; el agente las lista con getTools y la llama con executeTool. En esta clase lees la tool de búsqueda del kit, la llamas como la llamaría un agente y registras la tuya.

Empezar la lección

En esta lección vas a

  1. 1Los campos de una tool y las reglas de nombre y descripción
  2. 2inputSchema en JSON Schema, cerrado y descrito
  3. 3executeTool: entra un objeto, sale texto JSON
  4. 4Tu primera tool en extras.mjs

Objetivo: registrar una tool con nombre, descripción, inputSchema y execute, y llamarla como la llamaría un agente, viendo el resultado y la pantalla.

Fragmento de kit/pagina/ferramentas.mjs. La misma agenda.buscar atiende el formulario y la tool.

04 · Tu primera herramienta

El bloque copia la página a un ensayo, escribe un extras.mjs con contar_vagas y lo verifica. Para que valga en el kit, pega la misma lista en kit/pagina/extras.mjs.

Terminal · ensayo con contar_vagas
cd ~/projetos/formacao-webmcp-site-v72/kit
E=${TMPDIR:-/tmp}/ensaio-webmcp-site/a3; rm -rf $E; mkdir -p $E; cp -r pagina/. $E/
cat > $E/extras.mjs <<'FIM'
export function extras(agenda) {
  return [{
    name: 'contar_vagas',
    description: 'Soma as vagas livres das oficinas de um tema. Só lê: não reserva nada.',
    inputSchema: {
      type: 'object',
      properties: { tema: { type: 'string', enum: ['html', 'javascript', 'webmcp', 'mcp'], description: 'Tema da oficina.' } },
      required: ['tema'],
      additionalProperties: false
    },
    annotations: { readOnlyHint: true },
    async execute({ tema }) {
      const lista = agenda.buscar({ tema });
      return { tema, vagas: lista.reduce((soma, o) => soma + o.vagas, 0) };
    }
  }];
}
FIM
PAGINA=$E node scripts/listar.mjs nativo | tail -1
PAGINA=$E node scripts/executar.mjs nativo contar_vagas '{"tema":"html"}'; echo "saída: $?"
Ejemplo del repositorio
5 ferramentas registradas
== Chromium 156.0.8078.4 (Playwright) · modo: nativo

saída: 0
