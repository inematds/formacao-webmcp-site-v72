Clase 2 · 15 min

Entorno: flag, origin trial, polyfill y tres modos de prueba

No necesitas tener instalado un Chrome experimental para trabajar. El kit levanta la página en un servidor local y abre el mismo Chromium de Playwright en tres modos: sin la API, con el polyfill y con WebMCP nativo detrás de la flag de prueba. Sin costo y sin clave de API.

Empezar la lección

En esta lección vas a

  1. 1Clonar el kit e instalar con versiones fijadas
  2. 2Contexto seguro: https en producción, 127.0.0.1 en el ensayo
  3. 3Los tres modos: sem, polyfill y nativo
  4. 4Origin trial y flag en tu Chrome, cuando quieras verlo en vivo

Objetivo: armar el kit y ver la misma página en tres modos (sin API, polyfill, nativo) sin gastar cuota ni instalar un Chrome experimental.

01 · La misma página, tres navegadores

Haz clic en cada modo.

La API solo existe en contexto seguro: https o localhost/127.0.0.1. Por eso el kit sirve la página en 127.0.0.1.

Prueba siempre el modo Sem ("sin API"): es el que ve la mayoría de los visitantes.

02 · Clonar e instalar el kit

Versiones fijadas al 19/10/2026: @mcp-b/webmcp-polyfill 6.0.3 y playwright 1.64.0. El postinstall copia el polyfill a pagina/vendor/ (solo para el ensayo).

Terminal · clonar, instalar y descargar Chromium
git clone -q https://github.com/inematds/formacao-webmcp-site-v72 ~/projetos/formacao-webmcp-site-v72
cd ~/projetos/formacao-webmcp-site-v72/kit
npm ci
npx playwright install chromium
echo "saída: $?"

04 · Verlo en tu Chrome (opcional)

Experimental al 19/10/2026. Nada de esto es criterio de listo.

1. Flag

Abre chrome://flags/#enable-webmcp-testing, actívala y reinicia Chrome.

Ejecuta el servidor del kit y abre la URL que imprime.

Servidorcd kit && node scripts/servir.mjs

2. Polyfill

Sin la flag, añade ?ensaio=polyfill a la URL.

La página carga el polyfill de pagina/vendor/ y registra las mismas herramientas.

URLhttp://127.0.0.1:[porta]/?ensaio=polyfill

3. Inspector

Google publica la extensión Model Context Tool Inspector, que lista y llama a las tools con lenguaje natural.

Pide la clave de API de un modelo (Gemini). No es necesaria en este curso.

4. Producción

Registra tu dominio en el origin trial de WebMCP y pega el token en la meta tag de la parte superior de kit/pagina/index.html.

El token se registra para el dominio del sitio; en localhost, usa la flag.

05 · Práctica

Todo local, sin costo. Cada ejercicio termina con un listo cuando.

E1 · Kit instalado

10 min

Clona el repositorio del curso en ~/projetos e instala el kit con el bloque de arriba.

Listo cuando: El bloque termina en saída: 0 y ls ~/projetos/formacao-webmcp-site-v72/kit/pagina/vendor muestra webmcp-polyfill.js.

E2 · Tres modos

3 min

Ejecuta ambiente.mjs y compara las tres líneas "página:".

Listo cuando: node scripts/ambiente.mjs; echo "saída: $?" → página: sem, página: com, página: com y saída: 0.

E3 · ¿El modo Sem se rompe?

5 min

Ejecuta node scripts/servir.mjs, abre la URL en el navegador que usas todos los días (sin flag) y haz una búsqueda y una reserva desde la pantalla.

Listo cuando: La búsqueda muestra resultados y la reserva aparece en "Minhas reservas" sin ninguna tool registrada.
